# Bollettini TPS

Pagina web che sovrappone i rapporti (PDF) al modulo del rapporto di lavoro TPS vuoto e crea un unico PDF, in formato A5 (o A4), da stampare o inviare.

- I PDF vengono elaborati solo nel browser di chi usa la pagina: nessun file viene caricato su GitHub o altrove.
- `index.html`: la pagina.
- `bollettino-vuoto.pdf`: il modulo vuoto. Per cambiarlo, carica un nuovo PDF con lo **stesso nome** (sostituisce il vecchio).
- La posizione del testo si regola nella pagina, in "Regola posizione e modulo" (predefinito: 48.7 mm a destra, 22.2 mm in alto, misurati sul modulo originale).
